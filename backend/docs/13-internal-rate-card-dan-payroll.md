# Rate Card & Payroll

## 1. Asumsi dasar

| Parameter | Nilai asumsi | Catatan |
|---|---|---|
| Tarif borongan | Rp450 per SAM-menit | Asumsi, bukan data resmi |
| Hari kerja | 6 hari (Senin–Sabtu) | |
| Target harian | 450 SAM-menit per operator (±7,5 jam efektif) | |
| Kapasitas minggu 100% | 2.700 SAM-menit = Rp1.215.000 | Efisiensi nyata biasanya 85–97% |
| Rata-rata upah contoh | ±Rp1.100.900 per minggu (±Rp4,77 juta per bulan) | Lihat slip di bagian 4 |
| Acuan UMK Kabupaten Bandung 2026 | Rp3.972.202 per bulan (±Rp917.400 per minggu) | Berlaku 1 Januari 2026 (lihat sumber di bawah) |
| Uang makan | 12% dari total ongkos jahit periode | Dalam rentang kebijakan 10–15% |
| Bonus QC | Rp500 per pcs lolos | Asumsi |
| Overhead | Rp80.000.000 per bulan ÷ 20.000 pcs = Rp4.000 per pcs | Asumsi |

Catatan: upah borongan sebaiknya dipastikan setara atau di atas UMK. Ini asumsi demo, bukan nasihat hukum ketenagakerjaan. Verifikasi dengan konsultan atau Disnaker.

## 6. Bonus QC 3 arah (contoh)

- Order ORD-2026-014: 293 pcs lolos × Rp500 = Rp146.500 masuk pool.
- Contoh bulanan: 20.000 pcs diproduksi, 97,5% lolos = 19.500 pcs × Rp500 = Rp9.750.000. Dibagi 3 (2 Mandor + 1 Kepala Operasional) = Rp3.250.000 per orang.
