# Material Kain

## A. Kain teknis / outdoor
Contoh: nylon blend, polyester ripstop, fleece. Umumnya sintetis, ringan, rapat, sebagian anti-air.

| Aspek | Standar penanganan |
|---|---|
| Cutting | Pisau sangat tajam (servo/straight knife) agar tepi tidak meleleh atau koyak |
| Jarum | Microtex / set point, No. 9–11 (metrik 65–75) agar tidak meninggalkan lubang permanen |
| Kerapatan jahit | ±10–12 SPI |
| Setrika/steam | Suhu rendah, 110–120°C. Di atas itu bisa melelehkan nylon/polyester |
| Tinggi gelaran | Maksimal ±50 lapis |

## B. Kain rajut & tenun
Contoh: cotton combed, rayon, linen, CVC. Kelenturan dan kestabilan dimensi bervariasi.

| Aspek | Standar penanganan |
|---|---|
| Jarum kain rajut | Ball point No. 11–14 (metrik 75–90) agar tidak memutus rajutan (run defect) |
| Kerapatan jahit | ±12–14 SPI |
| Relaksasi | Kain rajut dan elastis diistirahatkan 12–24 jam sebelum dipotong |
| Uji susut | Sampel 50×50 cm dicuci dan dikeringkan (mengacu AATCC 135) untuk menghitung kompensasi pola |
| Tinggi gelaran | Maksimal ±100 lapis |

## Inspeksi kain masuk
Kain diinspeksi dengan sistem 4-titik (ASTM D5430). Lihat `06-kualitas-qc.md`.
