# Harga & Ketentuan Umum

> **Catatan untuk chatbot:** semua angka di file ini adalah **kisaran estimasi**, bukan penawaran resmi. Selalu sampaikan bahwa harga final ditentukan setelah tim melihat desain/tech pack, bahan, dan jumlah pesanan. Jangan menyebut komponen biaya internal (upah, overhead, margin).

## 1. Ketentuan umum

| Hal | Ketentuan (estimasi) |
|---|---|
| Minimal order (MOQ) | 50 pcs per model per warna. Di bawah itu hanya dengan persetujuan tim dan harga khusus |
| Skema | CMT, Semi-CMT, Full Package (lihat `02-skema-kerja-sama.md`) |
| Biaya sampel | Rp500.000 per model (termasuk pola dan 1 sampel). Revisi 1–2 kali gratis, revisi berikutnya Rp150.000 per revisi |
| Kredit biaya sampel | Biaya sampel dikurangkan dari tagihan jika pesanan massal dikonfirmasi dalam 60 hari |
| Lead time sampel | ±7–14 hari kerja sejak brief lengkap dan material sampel diterima |
| Lead time produksi massal | ±3–4 minggu untuk 300 pcs, terhitung sejak sampel disetujui dan bahan lolos inspeksi. Jumlah lebih besar dijadwalkan sesuai antrean |
| Pembayaran | DP 50% saat PO sebelum cutting. Pelunasan sebelum barang dikirim |
| Pengiriman | Serah terima dari Ciwidey (ex-factory). Ongkos kirim ditanggung klien kecuali disepakati lain |
| Pajak | Harga belum termasuk PPN (jika berlaku) |
| Kebijakan cacat | Produk cacat akibat proses produksi tidak ditagihkan. Cacat akibat bahan klien dibahas bersama |
| Sisa kain (CMT/Semi-CMT) | Dicatat dan dikembalikan ke klien bersama pengiriman |

## 3. Faktor yang membuat harga naik atau turun

- Kompleksitas desain (jumlah saku, lining, detail, jahitan khusus)
- Jenis kain (kain licin, elastis, atau berlapis membutuhkan penanganan khusus)
- Ukuran di luar standar (XXL ke atas) atau banyak variasi ukuran dan warna
- Label dan hangtag khusus, sablon, atau bordir (dikerjakan dan ditagih terpisah)
- Jumlah order dan jadwal (order mendesak bisa dikenakan biaya tambahan)

## 4. Skema Semi-CMT dan Full Package

- **Semi-CMT:** harga CMT + biaya trims/aksesoris yang kami sediakan (ritsleting, benang, label, polybag, dll.) sesuai BOM.
- **Full Package:** harga CMT + biaya bahan (kain dan trims) + biaya penanganan bahan (±10–15%).

Contoh ilustrasi Full Package untuk jaket windbreaker 300 pcs (**asumsi harga bahan, bukan data pasar terverifikasi**):

| Komponen | Hitungan | Per pcs |
|---|---|---|
| Kain ripstop | 1,9 m × Rp48.000 | Rp91.200 |
| Trims (ritsleting, tali, label, polybag, benang) | asumsi | Rp22.000 |
| Penanganan bahan | 12% × (Rp91.200 + Rp22.000) | Rp13.584 |
| Jasa CMT (300–999 pcs) | tabel di atas | Rp38.500 |
| **Estimasi Full Package** | | **±Rp165.300** |
