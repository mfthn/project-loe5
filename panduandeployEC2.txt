Launch server
Buka link login dari mentor
Pilih region yang diberikan mentor di kanan atas konsol.
Buka EC2 > Launch templates > main-ec2-templates > Actions >
Launch instance from template.
Jangan ubah tipe instance atau ukuran disk. Kalau ada pertanyaan key pair,
pilih untuk tidak menyertakannya.
Tambah tag: Key Owner , Value = username Anda persis (contoh
student_3 ) pada Resource types: Instances (dan Volumes
kalau ada).
Klik Launch instance. Buat satu server saja.

Alkademi

Ambil IP & connect
Tunggu state Running dan 2/2 checks passed, lalu tunggu ±3 menit sampai setup
awal selesai.
Salin Public IPv4 address dari tab Details. IP berubah setiap server di-stop/start.
Pilih server > Connect > tab Session Manager > Connect.
Di terminal jalankan sudo su - ec2-user lalu cloud-init status --wait.
Hasilnya harus status: done.

sudo su - ec2-user
cloud-init status --wait
TENTANG TERMINAL INI
Terminal ini berbasis web, terbuka langsung di AWS Console. Tombol Connect di
tab Session Manager membuka tab/jendela browser baru berisi terminal
interaktif yang langsung terhubung ke server EC2. Tidak perlu membuka aplikasi
terminal di laptop atau menggunakan SSH key tambahan.

Jalankan aplikasi
Pilih sesuai teknologi Anda
Node.js / Next.js
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
. ~/.nvm/nvm.sh
nvm install 22
npm install
export NODE_OPTIONS=--max-old-space-size=1536
npm run build
nohup npm start -- -H 0.0.0.0 -p 3000 > ~/app.log 2>&1 &
echo $! > ~/app.pid

Lewati npm run build kalau tidak ada langkah build. Express: nohup node server.js > ~/app.log 2>&1 & (listen 0.0.0.0:3000).

Python (FastAPI/Flask)

python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
nohup uvicorn main:app --host 0.0.0.0 --port 3000 > ~/app.log 2>&1 &
echo $! > ~/app.pid

Sesuaikan main:app dengan nama file Anda. Flask: flask run --host 0.0.0.0 --port 3000.

Docker
docker compose up -d --build

Pastikan port compose dipetakan ke 3000:3000. Build bisa lambat (server 1 GB RAM).
Port: Pastikan setiap kelompok pakai port yang berbeda (mis. 3000, 3001, 3002). Port inilah yang Anda submit di form pelaporan.

Konfigurasi PostgreSQL

Database & aplikasi di server yang sama (localhost) — jalankan via Session Manager setelah sudo su - ec2-user.
1. Install PostgreSQL Server
sudo dnf update -y
sudo dnf install -y postgresql15-server postgresql15

AL2 lama: pakai sudo amazon-linux-extras install postgresql15 postgresql-server sebagai gantinya.
2. Inisialisasi Database
sudo postgresql-setup --initdb

3. Jalankan & Aktifkan Service
sudo systemctl start postgresql
sudo systemctl enable postgresql
sudo systemctl status postgresql

4. Buat Database & User Aplikasi
sudo -u postgres psql

Di prompt psql, jalankan SQL berikut (sesuaikan nama db / user / password):
CREATE DATABASE myappdb;
CREATE USER myappuser WITH ENCRYPTED PASSWORD 'password_rahasia_kamu';
GRANT ALL PRIVILEGES ON DATABASE myappdb TO myappuser;
ALTER DATABASE myappdb OWNER TO myappuser;
\q

5. Hubungkan Aplikasi ke PostgreSQL
DATABASE_URL="postgresql://myappuser:password_rahasia_kamu@127.0.0.1:5432/myappdb"

Catatan keamanan: Tidak perlu buka port 5432 di Security Group EC2 — cukup listen di 127.0.0.1 di dalam server.

Test dari browser
Di server, cek aplikasi berjalan dengan curl -I http://localhost:3000 (harus 200 OK).

Di laptop, buka http://IP-PUBLIK:3000 — pakai http, bukan https.
Tes fitur yang memanggil Bedrock dari halaman web atau dengan curl.
